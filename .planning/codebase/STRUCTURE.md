## Naming Conventions

| Entity | Convention | Example |
|--------|-----------|---------|
| React components | PascalCase | `DashboardBody`, `DataTable` |
| Component files | camelCase.tsx | `dashboardBody.tsx`, `statcard.tsx` |
| UI primitive files | kebab-case.tsx | `dropdown-menu.tsx`, `data-table.tsx` |
| Type files | camelCase.ts | `offer.ts` |
| Constant files | kebab-case.ts | `sidebar-item.ts` |
| Hook files | use-*.ts | `use-mobile.ts` |
| Page files | `page.tsx` (Next.js convention) | |
| Layout files | `layout.tsx` (Next.js convention) | |

## Import Path Convention

All internal imports use the `@/*` alias:
```tsx
import { DataTable } from "@/components/merchant/offer/offerTable/data-table"
import { Offer } from "@/lib/types/offer"
import { cn } from "@/lib/utils"
import { sidebarItems } from "@/lib/constants/sidebar-item"
```

The `cn` package is re-exported from `lib/utils.ts` to maintain the conventional shadcn import path `@/lib/utils`.
