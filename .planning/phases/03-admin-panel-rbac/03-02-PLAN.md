# Plan 03-02: Admin Dashboard Layout with shadcn Components

**Status:** Pending
**Type:** UI/UX
**Priority:** High
**Effort:** 6 hours

## Objective

Create admin dashboard layout with navigation sidebar, responsive design, and shadcn/ui components to provide a professional admin interface for platform administration.

## Success Criteria

1. Required shadcn/ui components installed and configured
2. Admin layout with sidebar navigation implemented
3. Responsive design works on desktop, tablet, and mobile
4. Navigation structure matches admin routes (dashboard, users, merchants, analytics)
5. Layout integrates with auth state (shows user info, logout)
6. Dark mode support implemented
7. Loading states and error boundaries added

## Tasks

### Task 1: Install Required shadcn/ui Components

**Command:** Component installation

**Description:** Install all required shadcn/ui components for admin dashboard.

**Steps:**
1. Run `npx shadcn-ui@latest add card` - For dashboard stat cards
2. Run `npx shadcn-ui@latest add table` - For data tables
3. Run `npx shadcn-ui@latest add button` - For action buttons
4. Run `npx shadcn-ui@latest add dropdown-menu` - For row actions
5. Run `npx shadcn-ui@latest add dialog` - For modals
6. Run `npx shadcn-ui@latest add form` - For input forms
7. Run `npx shadcn-ui@latest add select` - For dropdowns
8. Run `npx shadcn-ui@latest add switch` - For toggles
9. Run `npx shadcn-ui@latest add badge` - For status badges
10. Run `npx shadcn-ui@latest add tabs` - For tab navigation
11. Run `npx shadcn-ui@latest add avatar` - For user avatars
12. Run `npx shadcn-ui@latest add input` - For text inputs
13. Run `npx shadcn-ui@latest add label` - For form labels
14. Run `npx shadcn-ui@latest add separator` - For visual separators
15. Run `npx shadcn-ui@latest add scroll-area` - For scrollable areas
16. Run `npx shadcn-ui@latest add sheet` - For mobile sidebar

**Acceptance Criteria:**
- All components installed successfully
- Components are properly configured in `components.json`
- Components are type-safe with TypeScript
