# PLAN 03-03: Geolocation Picker and Geofence Configuration

## Objective

Implement a map-based geolocation picker for setting branch coordinates and add geofence radius configuration to the branch form.

## Context

This plan enhances Plan 03-02's branch form with visual location selection. It adds a map component that allows merchants to click to set coordinates, search by address, and configure geofence radius for fraud detection.

## Tasks

### Task 1: Install and Configure MapLibre

**Files to modify:**
- `package.json` - add dependencies

**Implementation:**
1. Install MapLibre GL JS and React MapLibre:
   ```bash
   npm install maplibre-gl react-map-gl
   npm install -D @types/maplibre-gl
   ```
2. Install MapLibre CSS via CDN or import
3. Configure MapLibre in the project (if needed)

### Task 2: Create Geolocation Picker Component

**Files to create:**
- `components/branches/GeolocationPicker.tsx` - map-based coordinate picker

**Implementation:**
1. Create component using React Map GL (MapLibre):
   - Display map centered on Nepal (default: Kathmandu)
   - Add marker for current coordinates using MapLibre Marker component
   - Allow clicking map to set new coordinates (onClick handler)
   - Display current lat/lng values
   - Add zoom controls via MapLibre navigation controls
   - Use OpenStreetMap raster tiles via MapLibre style (free, no API key required)
2. Add manual coordinate input:
   - Latitude number input
   - Longitude number input
   - Update marker and map view when manual input changes
3. Add address search (optional, if time permits):
   - Use Nominatim (OpenStreetMap geocoding, free)
   - Search input field
   - Display results, click to pan map to location
4. Add "Use my location" button:
   - Use browser geolocation API
   - Fly map to user's location using MapLibre flyTo
   - Set coordinates from user location
5. Handle loading states for map and geolocation
6. Add error handling for geolocation permission denial

**Success criteria:**
- Map displays correctly with OpenStreetMap tiles
- Marker shows current coordinates
- Clicking map updates coordinates
- Manual input updates marker and map view
- Zoom controls work
- "Use my location" button works (with permission)
- Loading states display
- Errors handled gracefully

## Notes

- OpenStreetMap is free and requires no API key
- MapLibre GL JS provides vector-based maps with better performance than raster tiles
- Geofence radius is used for fraud detection (verify redemption location)
- Default radius of 500m is typical for retail geofencing
- Map may need z-index adjustment to display correctly in modal
- Browser geolocation requires HTTPS in production
- Address search via Nominatim is free but has rate limits
- MapLibre uses WebGL for rendering, ensuring smooth interactions
