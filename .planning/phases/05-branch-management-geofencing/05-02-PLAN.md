# Plan 04-02: Branch Creation Modal

## Objective
Create a branch creation form with React Hook Form and Zod validation, implement an operating hours schedule builder, add geolocation coordinate capture, and create a modal/dialog component for the form.

## Success Criteria
1. Branch creation form validates all inputs with Zod schemas
2. Operating hours schedule builder allows setting hours for each day
3. Geolocation capture gets current GPS coordinates
4. Modal/dialog component displays the form
5. Form submission calls createBranch API
6. Success/error handling with toast notifications
7. Form closes on successful creation

## Tasks

### Task 1: Create Branch Form Schema
**File**: `lib/merchant/schemas/branch-schema.ts` (or inline in form component)

**Description**: Create Zod validation schema for branch creation.

**Implementation Details**:
- Import `z` from `zod`
- Define schema matching `CreateBranchDto`:
  - `name`: string, min 2 chars, max 100 chars
  - `address`: string, min 5 chars, max 255 chars
  - `city`: string, min 2 chars, max 100 chars
  - `phone`: string, phone number regex
  - `lat`: number, min -90, max 90
  - `lng`: number, min -180, max 180
  - `geofenceRadius`: number, min 10, max 5000, optional
  - `operatingHours`: object with day keys, optional
- Add custom validation for phone format
- Add custom validation for coordinates
- Export schema as `createBranchSchema`

**Acceptance Criteria**:
- Schema compiles without errors
- Validation rules match backend DTOs
- Error messages are user-friendly

### Task 2: Create Operating Hours Schedule Builder
**File**: `components/merchant/operating-hours-builder.tsx`

**Description**: Create a component for setting operating hours for each day of the week.

**Implementation Details**:
- Create component with props:
  - `value: Record<string, { open: string; close: string; closed?: boolean }>`
  - `onChange: (value) => void`
- Render 7-day grid (Mon-Sun)
- Each day has:
  - "Closed" toggle switch
  - "Open" time input (HH:MM format)
  - "Close" time input (HH:MM format)
- Add "Copy to all" button to apply same hours to all days
- Add "Clear all" button to reset hours
- Use shadcn components: Switch, Input, Button
- Validate time format (HH:MM, 24-hour)
- Validate open < close time

**Acceptance Criteria**:
- Component renders 7-day grid
- Toggle switch marks day as closed
- Time inputs accept HH:MM format
- "Copy to all" applies hours to all days
- "Clear all" resets all hours
- Validation prevents invalid times

### Task 3: Create Geolocation Capture Component
**File**: `components/merchant/geolocation-picker.tsx`

**Description**: Create a component to capture GPS coordinates using browser Geolocation API.

**Implementation Details**:
- Create component with props:
  - `onLocation: (lat: number, lng: number) => void`
  - `lat?: number` - Current latitude
  - `lng?: number` - Current longitude
- Add "Get Current Location" button
- Use `navigator.geolocation.getCurrentPosition()`
- Handle permission errors
- Handle timeout errors
- Handle position unavailable errors
- Show loading state while fetching
- Display coordinates when captured
- Add manual input fields for lat/lng as fallback
- Validate coordinate ranges (lat: -90 to 90, lng: -180 to 180)

**Acceptance Criteria**:
- Button triggers geolocation API
- Loading state shows while fetching
- Coordinates display when captured
- Manual input works as fallback
- Errors are handled gracefully
- Validation prevents invalid coordinates

1. **Geolocation Permission**: Users may deny location permission. Mitigation: Provide manual input fallback.
2. **Operating Hours Complexity**: Schedule builder may be complex. Mitigation: Keep UI simple, add "Copy to all" feature.
3. **Form Validation**: Zod schema may not match backend exactly. Mitigation: Test with backend, adjust schema as needed.
